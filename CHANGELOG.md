# Changelog

All notable changes to `safari-mcp` are documented here.

## v0.1.4 — 2026-09-26

- Added a package metadata link to the changelog alongside the existing homepage and issue tracker links.
- Added repository-contract coverage for package maintenance URLs.
- Bumped package/runtime version to `0.1.4`.

## v0.1.3 — 2026-09-24

- Added release-history documentation and repository-contract checks.
- Included changelog, tests, CI workflow metadata, and bilingual README files in source distributions.
- Ran the GitHub Actions workflow for version tags as well as main-branch pushes.

## v0.1.2 — 2026-09-24

- Added repository-contract tests for required files, README local links/assets, real-Safari safety boundaries, CI coverage, and package/runtime version parity.
- Bumped package/runtime version to `0.1.2`.
- Published wheel, source distribution, and SHA256 checksums.

## v0.1.1 — 2026-09-23

- Modernized packaging license metadata to the current SPDX-style `license` and `license-files` fields.
- Added packaging metadata regression coverage and kept Python 3.10 test compatibility.

## v0.1.0 — 2026-09-16

- Initial public release.
- Added the Safari JXA core, CLI commands, MCP server entry point, bilingual documentation, demo assets, tests, and macOS CI.
